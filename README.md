## CC 图库管理 v1.0.0

本地优先的照片 / 视频 / 音频管理器。不联网、不上传、不扫描磁盘，只有你导入的内容才会进入图库。

### 功能
- 文件夹或单文件导入：JPG/PNG/WebP/GIF/BMP、MP4/MOV/WebM/MKV、MP3/WAV/FLAC/M4A
- 自动分区：人物 / 动物 / 风景 / 建筑 / 美食，支持手动校正
- 人物标注与按人检索、相册、收藏、标签、星级
- 搜索、排序、缩略图密度、批量选择与批量操作
- 图片导出与转换：JPG / PNG / WebP、质量与最长边压缩、命名规则
- 批量旋转与翻转
- 视频转 MP4（H.264 + Opus）/ WebM（VP9 + Opus），提取 MP3 / WAV 音轨
- 黑白双主题，液态玻璃界面与弹性动效

### 下载与使用
1. 下载下方 `CC图库管理-Windows-x64.zip`
2. 解压到任意目录（建议非系统盘）
3. 双击 `CC 图库管理.exe`

无需安装，不依赖浏览器。首次运行如出现 SmartScreen 提示，点「更多信息 → 仍要运行」。

### 源码
本仓库包含完整源码：`index.html`（界面与功能）、`electron/`（桌面版启动脚本）。
构建方法见 `README.md`。

### 说明
- 图库数据保存在 `%APPDATA%\CC 图库管理`，不上传、不联网
- 「移出图库」只删除软件内副本，不会动磁盘上的原文件
- 视频转码为实时编码，耗时约等于视频时长
- 系统要求：Windows 10 / 11（64 位）
